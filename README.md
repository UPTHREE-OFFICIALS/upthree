# upthree

UPTHREE — Web Development Studio marketing site.

Built with Next.js 15 (App Router), Tailwind CSS and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Routes

- `/` — homepage (hero, concept demos, services diagram, process, contact, FAQ)
- `/services` — full diagrammatic service flow
- `/api/inquiries` — project inquiry endpoint
